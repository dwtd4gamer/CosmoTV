# Dulo Addon Repository

A Kodi addon for streaming movies and TV shows from dulo.tv.

## Installation

1. In Kodi: **Add-ons** → **Install from zip file**
2. Select `plugin.video.dulo.zip`
3. Go to **Add-ons** → **Video add-ons** → **Dulo Movies & TV**

## Requirements

- Kodi 19.0+
- Python 3.8+
- `requests` library
- `beautifulsoup4` library

Install via: Settings → System → Manage dependencies

## Important Notes

- This addon requires internet connection
- Content availability depends on dulo.tv
- May require CSS selector updates if site structure changes
- For personal/educational use only

## Troubleshooting

Check Kodi logs: Settings → System → Logging → Enable → View log
